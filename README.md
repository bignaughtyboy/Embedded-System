# 🔧 Embedded System Basic Experiments

> **Embedded System Basic Experiment Examples**

This repository contains example files and source code created during the **Embedded System Basic Experiments** course.

The repository is organized to keep each experiment and its example files in one place, making them easy to manage, review, and update.

This repository is used to:

* Organize experiment example files
* Keep track of coursework
* Store source code from each experiment
* Review previous experiments
* Continuously update examples throughout the course
